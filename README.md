# 📝 TaskMaster Pro - To-Do Web Application

A modern, responsive, and feature-rich To-Do List application built with **React.js** and **Tailwind CSS**. Designed to help users efficiently organize their daily tasks with custom categories and real-time filtering options.

##  Features
- **Task Management**: Add, edit, delete, and mark tasks as completed seamlessly.
- **Categories**: Organize tasks into different segments like **Work**, **Study**, and **Personal** with color-coded badges.
- **Filtering Tabs**: Easily filter tasks by **All**, **Active**, and **Completed** views.
- **Local Storage Sync**: Automatically saves your tasks to the browser's local storage so you never lose your data on refresh.
- **Responsive Design**: Clean and modern UI styled with Tailwind CSS.

##  Tech Stack
- **Frontend**: React.js (Vite)
- **Styling**: Tailwind CSS
- **Icons / Utilities**: UUID for unique task identification
- **Storage**: Browser LocalStorage
